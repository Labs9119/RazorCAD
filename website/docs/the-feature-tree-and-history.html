The Feature Tree and History

Editing features

  • Double-click a feature, or right-click ▸ Edit Feature, to open its Property panel.
  • Select a feature and press Del (or Edit ▸ Delete) to delete it. Only that feature goes: the sketches, 3D sketches and features it was made from stay, shown on their own in the tree again.
  • Edit ▸ Undo / Redo (Ctrl+Z / Ctrl+Y) works on the whole part history.
  • Rebuild (Ctrl+B, or the quick button) rebuilds the part.
  • A feature that fails shows an error in the tree so you can fix or re-pick its references (see Fix References).

References that follow edits

Features that use picked edges and faces (fillets, chamfers, shells, drafts, axes…) find them again after the model changes. An edge made by an extrusion (a boss, cut or pocket from a sketch, without draft or thin walls) is also named by what made it: the sketch curve it runs along and which end of the extrusion it is at (its top or bottom rim, a pocket's floor), or the sketch point it runs from. After a change it is looked for by that name first, so when you move a circle in a sketch of several, a fillet on its boss goes with it, even if another boss now stands where it was. Other edges, and named ones the name does not settle (an edge split in two by a later cut, say), are found by where they were. An edge remembers the faces on its two sides and whether it is an outside or inside corner. When a dimension moves it so far that other edges now lie nearer its old place, the right edge is still found, and an edge of another kind is not taken for it. A face that moved is found as the face facing the same way that is clearly nearest. A reference found again this way is updated, so it keeps following the model.

Fix References

Tools ▸ Fix References… lists every feature that failed to rebuild, what went wrong and which of its edges or faces are no longer in the model. Open it also by clicking the red error count in the status bar, or by right-clicking a failed feature. For each feature:

ButtonWhat it does
EditOpens the feature (or sketch) to pick its references again
Remove missingKeeps the references that are still found and drops the others
SuppressLeaves the feature out for now

Fix them from the top: a feature can fail only because one above it did. The list follows every rebuild while it is open.

Rollback bar

The blue line at the bottom of the tree. Drag it up, or right-click a feature ▸ Roll Back / Roll to End. Features below the bar are suppressed, and new features are inserted above it.

Reordering features

Drag a feature up or down the tree. Its absorbed sketch moves with it. A move that would break a reference is refused with the reason.

Reference arrows

Select a feature in the tree. Blue arrows come from what it uses; purple arrows go to what uses it.

Tree symbols

Sheet metal features and bodies have their own icons. Under-defined sketches show (-). Sketches absorbed by features are hidden by default.
